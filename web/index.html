KNOW YOUR MODEL

A transparent experiment.

This is a deterministic, single-CPU simulation with one CPU burst per process. It does not model I/O, multicore execution, or context-switch duration. SJF and SRTF know burst lengths in advance.

Waiting = completion − arrival − burst. Response = first start − arrival. Lower priority numbers run first. Ties use arrival time, then input order. RR admits new arrivals before requeuing the interrupted process.

Benchmarks report mean ± sample standard deviation across workloads, not a confidence interval. Generated “interactive” workloads contain short CPU jobs, not interactive I/O behavior. Read the scheduling foundations ↗
